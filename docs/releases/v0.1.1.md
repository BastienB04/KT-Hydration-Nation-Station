Ribbit's About screen now says **“A friendly frog for daily sips and hydration tracking.”** and shows **Version 0.1.1**. This small update keeps the same hydration features, settings and local data format.

Already using v0.1.0? Open **About → Check for updates**, choose **Download update**, then **Restart now** when ready. Choose **Later** to keep using your current version. Ribbit verifies the download and its signed version before installation, and keeps your settings and hydration history.

New installation: [download the Windows x64 installer](https://github.com/BastienB04/KT-Hydration-Nation-Station/releases/latest/download/KT-Hydration-Nation-Station-setup.exe) and follow the [installation instructions](https://github.com/BastienB04/KT-Hydration-Nation-Station#install-on-windows). The README now explains Microsoft Edge's **Keep → Keep anyway** download warning, including the option under the down arrow beside **Delete**.

The app installs for your Windows account with no app administrator elevation expected. The installer remains unsigned for Authenticode, so SmartScreen may show **Unknown publisher**; for this official download, use **More info → Run anyway** and keep SmartScreen and Defender enabled. Updater signing does not remove those warnings.

Windows 11 x64 is the physically tested platform; Windows 10 21H2 or later is an intended compatibility target that has not been physically validated. No accounts, telemetry, cloud storage or recurring fee; optional GitHub update checks/downloads do not send your hydration data.
